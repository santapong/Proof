## Prompt

Use case: ads-marketing.
Asset type: a polished raster banner for the GitHub README of the open-source project Proof, a governed multi-agent engineering workflow toolkit for software teams.
Create one panoramic landscape image, ideally 1536 x 640 pixels, wide 12:5 composition. Make the image itself the finished banner, with clean rectangular edges.
Visual concept: precise, understated engineering editorial design. A deep charcoal technical drafting surface with a faint grid; a sparse three-dimensional workflow of small connected modules, a few parallel paths converging through one clear verification gate with a restrained check mark. Finely machined dark metal and frosted translucent surfaces, subtle cyan/teal light tracing the verified path, neutral ivory typography. The focus is organized software work and verification, not robots or a brain. Professional, calm, architectural, very legible at GitHub README width. Generous negative space and deliberate balance between typography and workflow illustration; avoid overcrowding.
Text must appear verbatim, with only these two lines:
"Proof"
"Governed multi-agent workflows"
Use large elegant modern sans-serif typography for Proof, smaller clean text for the second line. Accurate spelling. Keep all text and important visual content within a safe inset of 8% from edges. No additional words, pseudo-code, metrics, feature counts, logos, badges, gradients behind every element, watermarks, screenshot framing, or claims of autonomous merging. High-quality crisp typography and refined visual depth.
